## 📋 **Quick Reference: Field Relationships**

### **Tempo Guidelines:**
- **Hip-Hop/Trap/Drill:** 140-150 BPM
- **Rock:** 100-120 BPM
- **Electronic/EDM:** 128 BPM
- **Jazz/Lo-Fi:** 70-90 BPM
- **Ambient:** 60-70 BPM
- **R&B/Pop:** 90-110 BPM

### **Bars Guidelines:**
- **Intro/Ending:** 4 bars (shorter, sets up/ends track)
- **Middle/Bridge:** 4-8 bars (transitional)
- **Drop/Chorus:** 8 bars (main sections, longer)

### **Preset + Style Combinations:**
- **Dark + Trap/Drill:** Aggressive, minimal
- **Energetic + Electronic:** Uplifting, powerful
- **Chill + Jazz:** Melodic, smooth
- **Atmospheric + Ambient:** Epic, spacious
- **Melodic + Pop/R&B:** Uplifting, catchy

### **Instrumentation + Style:**
- **Trap/Drill:** 808, hi-hats, kick, snare
- **Rock:** Guitar, bass, drums
- **Electronic:** Synth, pads, 808
- **Jazz:** Piano, bass, drums
- **Ambient:** Strings, pads

### **Pitch Curve by Section:**
- **Intro:** Stable (builds foundation)
- **Middle:** Stable → slight rise (builds energy)
- **Bridge:** Falling or Rising (creates contrast)
- **Drop:** Rising (peak energy)
- **Chorus:** Stable (maintains energy)
- **Ending:** Stable → slight fall (natural fade)

## 💡 **Pro Tips**

1. **Keep Tempo Consistent:** All sections should use the same tempo (or vary by ±5 BPM max)

2. **Harmonic Flow:** Use related chord progressions across sections (same key, related chords)

3. **Energy Arc:** Build from low (Intro) → high (Drop/Chorus) → low (Ending)

4. **Instrumentation Overlap:** Keep 1-2 core instruments consistent across all sections

5. **Preset Progression:** Use darker/calmer presets for Intro/Ending, energetic for Drop/Chorus

6. **Bars Balance:** Use 4 bars for transitions, 8 bars for main sections
